Nine years, one long climb

It began the way a lot of these stories begin: a ticket queue, a headset, and a list of things I did not yet understand. Basic IT support in Toronto. Password resets, printers, the occasional machine that simply refused to cooperate. What stuck with me wasn't the work — it was the feeling of tracing a problem back to its cause and finding out there was a whole layer down there I'd never looked at.

So I went down a layer. Networking took over my evenings. I learned what was actually happening on the wire, then in the switch, then across the enterprise, and I earned my CCNA and CCNP Enterprise along the way. Switches, firewalls, routing, segmentation — the plumbing everything else quietly depends on. It was the first time a subject didn't run out on me. Every answer opened another question, and I liked that.

Linux came next, and it came hard. Not the tutorial version — the kernel, the filesystem, the process model, the parts that make you slow down. Kubernetes followed naturally from there, and the CKA gave me a way to prove I understood it under pressure. Then the cloud: AZ-104, AZ-305, and a Terraform Associate, because once you've built infrastructure by hand enough times you start wanting to describe it in a file and let the machine do the rest.

That's how I landed in DevOps, and it's where the two halves of my career started talking to each other. I built pipelines, shipped containerized workloads into dev and prod, and spent my days between the people writing the code and the systems running it. Working that closely with developers did something I didn't expect: it made me want to write the code myself.

Python first. Then databases — PostgreSQL, MSSQL, MongoDB — and the front end, HTML, CSS, JavaScript, then the frameworks that sit on top of them. I wanted the foundations to be real rather than borrowed, so I went back to school and earned a Diploma in Computer Programming from Sheridan College to put structure under what I'd been teaching myself.

I think of all of it as one continuous thing. The support desk taught me to listen to a problem. Networking taught me how things actually connect. Linux and Kubernetes taught me what's really happening when software runs. Cloud and Terraform taught me to build systems you can rebuild. DevOps taught me how software reaches people. Now I'm writing that software, and none of the earlier layers went away — they're the reason I can see the whole path a request takes, from the port it arrives on to the line of code that answers it.

Software engineering is where I'm headed. It's also just the next layer, and I have no plans to stop climbing.
