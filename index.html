    I never stopped at the layer I was on.

    I didn't plan this path. I followed my curiosity, and each time I understood one layer well enough to feel comfortable, the one above it started to look interesting. Ten years later I'm still doing the same thing.

    The chapters are numbered like rack units. U1 is where I started.

    1. U1 Support desk

      It started with basic IT support.

      My first job in tech was helping people whose computers weren't doing what they needed. It taught me to stay calm around a broken system and to explain it plainly to the person who just wants to get back to work. It also left me curious about what was really going on behind each ticket.

    2. U2 Networking

      Then I went deep on the network.

      I loved learning more than any single job title asked of me, so I followed that down into infrastructure. I worked on switches, firewalls and enterprise networking, spent my days working on Cisco and FortiGate, and earned my CCNA and CCNP Enterprise along the way.

      • CCNA
      • CCNP Enterprise
      • Cisco
      • FortiGate
    3. U3 Linux and containers

      Linux changed how I saw everything above it.

      I learned Linux deeply and worked on Linux VMs, then took the next step into orchestrating containerized workloads. I earned my Certified Kubernetes Administrator (CKA) to back it up.

      • Linux
      • Kubernetes
      • CKA
    4. U4 Cloud Where I work today

      The companies I worked for run on Microsoft and Azure.

      So I learned Azure properly. AZ-104 covered running it day to day, and AZ-305 covered designing solutions on it. Today I'm a Cloud Infrastructure Engineer, and this is the layer I spend most of my time on.

      • Azure
      • AZ-104
      • AZ-305
    5. U5 Code-defined infra

      Infrastructure became something I write.

      We were deploying a lot of infrastructure at scale, and it made sense to do that through code. I earned my Terraform Associate and started working heavily in DevOps: building pipelines and deploying containerized workloads into dev and prod environments.

      • Terraform
      • CI/CD pipelines
      • Containers
    6. U6 Software Still growing

      Working with developers made me want to build.

      I got more and more interested in the code that was being shipped. I learned Python, TypeScript and Java, then SQL databases with PostgreSQL and SQL Server, MongoDB, and the frontend side with HTML, CSS, JavaScript and a wide range of frameworks. A Diploma in Computer Programming from Sheridan College gave that growing knowledge a solid foundation.

      • Python
      • TypeScript
      • Java
      • PostgreSQL
      • SQL Server
      • MongoDB
      • Frontend
